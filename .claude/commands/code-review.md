# コードレビューコマンド

以下のファイル/PRに対してコードレビューを実施してください: $ARGUMENTS

## レビュー観点

### コード品質
- [ ] コーディング規約に準拠しているか（PEP 8、ESLint等）
- [ ] 命名規則が適切か
- [ ] 適切なコメントが付与されているか
- [ ] 重複コードがないか
- [ ] 複雑度が適切か（関数が長すぎないか）

### セキュリティ
- [ ] 入力バリデーションが適切か
- [ ] SQLインジェクション対策
- [ ] XSS対策
- [ ] 認証・認可が適切か
- [ ] 機密情報がハードコードされていないか

### パフォーマンス
- [ ] N+1問題がないか
- [ ] 不要なループや計算がないか
- [ ] キャッシュの活用は適切か

### テスト
- [ ] テストが存在するか
- [ ] エッジケースがカバーされているか
- [ ] テストが意味のある検証を行っているか

### アーキテクチャ
- [ ] 責務が適切に分離されているか
- [ ] 依存関係が適切か
- [ ] 拡張性を考慮しているか

## 出力形式

```markdown
## レビュー結果

### サマリー
[全体的な評価]

### 重要な指摘事項
1. [ファイル名:行番号] - [指摘内容]
2. ...

### 改善提案
1. [提案内容]
2. ...

### 良い点
1. [良い点]
2. ...
```

## 注意事項

- 建設的なフィードバックを心がけること
- 重要度（Critical/Major/Minor）を明示すること
- 具体的な改善コードを提案すること
