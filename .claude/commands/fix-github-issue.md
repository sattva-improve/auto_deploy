# GitHubイシュー修正コマンド

GitHubイシュー #$ARGUMENTS を分析して修正してください。

## 手順

1. `gh issue view $ARGUMENTS` でイシュー詳細を取得
2. 問題を理解し、影響範囲を特定
3. 関連するコードベースを検索
4. 修正を実装
5. テストを作成・実行して検証
6. Lintとタイプチェックをパス
7. 説明的なコミットメッセージを作成
8. ブランチをプッシュしてPRを作成

## 注意事項

- 修正前に必ず問題の根本原因を特定すること
- テストなしで修正を完了としないこと
- PRの説明には修正内容と影響範囲を明記すること
- GitHub CLI (`gh`) を使用してGitHub操作を行うこと
